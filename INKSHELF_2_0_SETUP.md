# InkShelf 2.0 development plan

This file belongs to the experimental `inkshelf-2.0` branch. Keep stable `main` unchanged.

## Initial milestones

1. Validate the development APK build.
2. Establish reusable dark-purple/black UI design components.
3. Redesign Comic Details, with current-issue cover imagery and unchanged reader and download controls.
4. Add accurate metadata and description fallbacks, without overwriting user edits.
5. Incrementally redesign Library, Discover and Home.
6. Add daily comic themes with three recommendations (new/trending, classic, acclaimed), library badges and 90-day rotation where possible.

## Safety

- Protect Panel Flow, library data, backups, extensions and existing reader functionality.
- Build and test each small change before merging.
- Use original or appropriately licensed promotional assets.
