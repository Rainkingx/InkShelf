# Built-in cinematic splash artwork

Place these five WebP images in this directory:

- 01_iron_man.webp
- 02_superman.webp
- 03_spider_man.webp
- 04_flash.webp
- 05_inkshelf_logo.webp

The animation uses this exact order. Keep the first four transparent. The final image is the complete InkShelf logo. The optional Doom rune is independent. Local artwork remains private and can still be selected in Appearance. Only distribute images you have permission to redistribute.
