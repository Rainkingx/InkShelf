# InkShelf v2.0.3

## Reader appearance fix

- Fixed low-contrast bottom reader controls when using light themes.
- Chapter panel, drag handle, chapter list and bookmark colours now match the selected InkShelf theme.
- Improved system navigation bar contrast when reader controls are visible.
- All six light themes and existing dark themes remain available.
- No changes to page rendering, reading controls' behaviour or the reading engine.

## Updating

This stable update retains the existing Android package identity and signing key. Back up your library before updating. InkShelf Dev remains a separate installation.

InkShelf is an independent reader based on TachiyomiJ2K. Third-party sources and services remain separate. Use lawful sources and respect rights holders.
