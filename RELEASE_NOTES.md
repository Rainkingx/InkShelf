# ARC v2.1.0 — Archive. Read. Collect.

InkShelf has a new identity: **ARC**. The same reader, library and features, with a new name and visual branding.

## What's new

- New ARC app name and simplified purple launcher emblem.
- Custom ARC header wordmark with a fine illuminated underline, adapting to the active theme.
- One cinematic ARC splash with native animation, tap to skip and optional custom artwork.
- Updated onboarding, settings, notifications, update dialog and other app-facing branding.
- Existing themes, Events, The Pulse, Release Radar, downloads, library and reader remain available.
- Existing storage locations are retained so the rebrand does not redirect downloads, backups or imported local comics.

## Updating from InkShelf

Install this release as an update over the existing stable InkShelf installation. The Android package ID and signing identity are unchanged; the release workflow verifies the certificate and version code against v2.0.3 before publication. Export a backup before updating as a precaution.

The download is still named `InkShelf.apk` and the GitHub repository URL is unchanged to keep updates compatible with older versions. The installed app appears as **ARC**. ARC Dev remains a separate installation.

ARC is an independent reader based on TachiyomiJ2K. Third-party sources and services remain separate. Use lawful sources and respect rights holders.
