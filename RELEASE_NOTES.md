# InkShelf 2.0 — Public Beta 3

A focused reliability update for fresh installations and offline reading.

## Changes

- Prompts for storage permission before downloading individual issues, event issues or resuming the download queue.
- Opens the relevant Android storage settings directly.
- Checks permission before creating download directories and reports invalid download locations more clearly.
- Keeps online reading available without granting offline storage access.
- Retains the in-app updater introduced in Beta 2.

## Updating

Public Beta 2 users can check for updates in Menu. If needed, download **InkShelf.apk** from this release and install it over the previous public beta. Back up your library first. The public app uses the same package ID and signing certificate. Development APKs remain separate.

After granting storage access, return to InkShelf and tap download again. This release is a beta; please report reproducible issues with your device, Android version and app version.

InkShelf is an independent reader based on TachiyomiJ2K. Third-party sources and services remain separate. Use lawful sources and respect rights holders. See the README and Apache-2.0 licence.
