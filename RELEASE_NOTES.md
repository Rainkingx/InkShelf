# InkShelf 2.0 — Public Beta 16

- Maintenance release to test the in-app update flow and randomized comic-book messages introduced in Beta 14.
- No new reader, Discover, Spotlight or extension functionality. All Beta 15 improvements remain in place.

## Updating

Use the in-app update notification to install Beta 16. Package identity and release signing remain unchanged. Back up your library before updating.

This is a prerelease. InkShelf is an independent reader based on TachiyomiJ2K. Third-party sources and services remain separate. Use lawful sources and respect rights holders.
